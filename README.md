# FP Dual Conecta A&G

Plataforma de gestión de la Formación en Empresa u Organismo Equiparado (FEOE) para la familia profesional de Administración y Gestión.

## Estado del repositorio

Repositorio inicializado. El código de la versión 3.6 está pendiente de incorporación desde el paquete de distribución para Ubuntu. Este repositorio todavía no contiene una instalación funcional.

## Instalación prevista

Una vez incorporado el código fuente, ejecutar `sudo bash ubuntu/install.sh` en Ubuntu Server. El administrador se crea durante la instalación; Resend y los parámetros funcionales se configuran desde el panel privado.

## Privacidad

No publicar claves de Resend, contraseñas, expedientes, datos de alumnado ni copias de seguridad. Revisar los datos iniciales del directorio antes de publicarlos en un repositorio público.
